Control.Monad.Prompt

Description

Re-exports Promptable, the typeclass that attaches a default prompting strategy to a type.

The program vocabulary itself — promptSingle, context, promptTools and the rest — lives in Control.Monad.Prompt.Effect, expressed as effectful effects rather than as a bespoke monad transformer. Runner configuration (PromptConfig) and the interpreters (runPrompt, runPromptResultEff) live there too.

The class method prompt comes from this module, the runner and context from Control.Monad.Prompt.Effect, so a program imports both (the names do not clash, since Control.Monad.Prompt.Effect exports no prompt):

import Control.Monad.Prompt
import Control.Monad.Prompt.Effect (context, defaultPromptConfig, runPromptResultEff)

result <- runPromptResultEff backend defaultPromptConfig $ do
  context "The user's name is Alice."
  prompt @User
