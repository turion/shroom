# Revision history for shroom

## 0.1.0.0 -- 2026-11-27

* First release. Typed LLM prompting on `effectful`: a program written with `context` and `prompt`
  gets back a typed Haskell value, retried when a reply fails to parse or breaks a property, and
  may offer the model tools its type lists. Released on an unsuspecting world.
