shroom

shroom builds typed LLM conversations. A monadic program written with context and prompt returns a typed Haskell value, or a descriptive error: a type is described to the model through its schema, the response is parsed back into it, and a response that fails to parse or breaks a stated property is retried. The package includes the prompt monad and its effect interface, deriving via Generically, tool calls, and a mock backend that reads responses from files. The classes describing types live in shroom-class, which this package re-exports.

shroom ships no backend for a real model: shroom-baikai supplies one for Claude and for OpenAI-compatible hosts such as a local Ollama.
