Description

Three tools, each a Toolable type with a ToolHandler to run it:

  • webFetchHandler runs WebFetch: an HTTP GET whose HTML is stripped and whose text is cut to 2000 characters.
  • duckDuckGoSearchHandler runs DuckDuckGoSearch, the DuckDuckGo Instant Answer API. It suits named entities (people, places, concepts) that have a Wikipedia article, and returns a short abstract with a URL.
  • wikipediaSearchHandler runs WikipediaSearch, the Wikipedia OpenSearch API. It returns up to 5 article titles and URLs for any query.

A program that offers these tools has them in its constraints and is run with one runTool per handler. See Control.Monad.Prompt.Tool for toolBinding, which offers a tool to the model:

result <- runPromptResultEff backend defaultPromptConfig $
  runTool webFetchHandler $
    runTool duckDuckGoSearchHandler $
      runTool wikipediaSearchHandler
        myProgram

Searching with DuckDuckGo

newtype DuckDuckGoSearch Source #

A DuckDuckGo Instant Answer search query.

Limitations: This uses the DuckDuckGo Instant Answer API, which only returns results for well-known named entities (people, places, concepts) that have a dedicated Wikipedia article. Vague or multi-word queries (e.g. "celebrity names", "Haskell conference speakers") will return "No result found". For general search use WikipediaSearch instead.
