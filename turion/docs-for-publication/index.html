shroom documentation

Start here: begin with Control.Monad.Prompt in shroom. Add shroom-baikai to talk to a real model, and use shroom-class on its own when you only want the type-description classes.

  • shroom: type-safe, structured LLM prompting for Haskell; the monadic prompt interface and the tools a model can call.
  • shroom-baikai: runs a shroom program against Claude or an OpenAI-compatible server, such as a local Ollama, through baikai.
  • shroom-class: the classes that describe a Haskell type to a model, with Template Haskell that derives them from Haddock comments.
